# JavacParserTest Extracted Cases

Extracted from OpenJDK `test/langtools/tools/javac/parser/JavacParserTest.java`.

- `cases/`: standalone Java source snippets extracted from `String code = ...` test cases.
- `manifest.tsv`: provenance and coarse labels. `has_expected_diagnostics=true` means the originating OpenJDK test asserted one or more `compiler.err.*`, `compiler.misc.*`, or `compiler.warn.*` diagnostics.
